Обновлено: 2026-11-05. Контекст: generic-спроса на skool-инструменты в Google нет (см. google-ads-keywords.md), но бренд `skoolkit` ищут 6 600/мес. Ниша растёт внутри экосистемы Skool, поиск ловит бренд потом.

## Часть 1. Каналы дистрибуции внутри экосистемы (по данным, не фантазии)

### Как растут в этой нише (паттерн SkoolKit / StickyHive)

1. **Платные обзоры/фичи в Skool-сообществах инфлюенсеров.** SkoolKit продвигается через «Skool Growth with Carolina» (skool.com/skool-school-4308) — VIP-реплей «SkoolKit Review». Это их главный видимый канал.
2. **SEO-блог по skool-запросам.** StickyHive построила контент-хаб stickyhive.ai/skool/* (automation tools, community management software, grow a skool community) — забирает тот малый generic-спрос, что есть, + качает authority. Цены: Solo $29 / Growth $49 / Scale $99.
3. **Карточка CWS** — у SkoolKit формулировка «All 8 tools live today» + конверсия через «jobs you keep putting off».
4. **Skool Games / Skoolers** (сообщество Хормози) — там тусуются владельцы, которые УЖЕ платят за инструменты; лидерборды MRR = список горячих клиентов.

## Часть 2. Payment Recovery — скелет фичи (конёк SkoolKit, который мы можем сделать лучше)

### Почему это фича №1 по деньгам
У платного сообщества (200 мемберов × $99) involuntary churn с карт = 1-3% в месяц ≈ $200-600/мес потерянной MRR. Инструмент, возвращающий половину, окупается навсегда. SkoolKit продаёт это как «Payment Recovery» + «Churn Hero». Generic-рынок dunning (Churnbuster, Baremetrics) стоит $249+/мес — на нише Skool пусто и дорого.

### Механика на нашем стеке (SKapi уже умеет всё нужное)

```
┌─ Монитор (cron, есть pattern: join_request_monitor) ─────────────┐
│ 1. GET api2.skool.com/groups/{gid}/members?status=...            │
│    (recon: найти в бандле Skool статус past_due/grace/lapsed —   │
│     у Skool есть транзакции и статусы подписки в API монетизации)│
│ 2. Диф с прошлым снапшотом (community_members таблица есть):     │
│    активный вчера → past_due сегодня = кандидат на recovery      │
└──────────────────────────────────────────────────────────────────┘
┌─ Recovery-воронка ──────────────────────────────────────────────┐
│ 3. Канал A: Skool DM владельца сообщества →_membeр (api2 DM,     │
│    у нас есть check_messages — отправка догматично recon)        │
│    Канал B: email (email_members уже работает в publish!)        │
│ 4. Секвенс (3 касания):                                         │
│    T+1ч:  «карка не прошла, обнови карту» + прямая ссылка       │
│           skool.com/{group}/settings/payment                    │
│    T+3д:  напоминание + что теряет (доступы/геймификация)       │
│    T+7д:  прощальное + оффер вернуться (опционально скидка)     │
│ 5. AI-персонализация сообщений — уже есть (ai_reply, GLM)       │
└──────────────────────────────────────────────────────────────────┘
┌─ Отчёт в дашборд ───────────────────────────────────────────────┐
│ 6. Метрика: failed → recovered, $ saved MTD (транзакции из API) │
└──────────────────────────────────────────────────────────────────┘
```

### Что уже есть / что копать

| Компонент | Статус |
|---|---|
| Монитор-скелет (WS + polling) | ✅ join_request_monitor, messages_monitor — копировать |
| Таблица мемберов + sync | ✅ community_members + COMMUNITY_SYNC_JWT |
| Email-канал | ✅ notify=members в /posts |
| AI-тексты | ✅ ai_reply (Z.ai GLM) |
| **Recon нужен:** статус подписки/past_due в api2 (grep бандла: `transactions`, `subscription`, `pastDue`) | ⬜ 1-2 дня по бандлу `/SkoolKit _ Skool CRM Toolkit_files/` |
| Отправка DM через api2 | ⬜ проверить эндпоинт в бандле |
| Grace period Skool (сколько дней до отселения) | ⬜ docs/help.skool.com |

### Продуктовое решение
Не делать «ещё один комбайн» — сделать **«Payment Recovery от API-компании»**: модуль в подписку Skapi (Pro), с публичной метрикой «$ recovered» на лендинге. Это ROI-история, которую SkoolKit прячет внутри комбайна, а мы можем показать числом.

### Порядок работ
1. Recon по бандлу (статусы подписки, DM-эндпоинт) — 1-2 дня
2. Монитор past_due + снапшоты — 2 дня
3. Секвенс DM/email + шаблоны AI — 2-3 дня
4. Дашборд-виджет «$ saved» — 1 день
5. Лендинг фичи + пост в 5 Skool-сообществах (шаг 1 плана атаки) — 1 день
